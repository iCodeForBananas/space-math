# Space Math 🚀

A space-themed math game for kids in kindergarten through grade 3. It covers
counting, addition and subtraction, place value, times tables, fractions,
area and perimeter, following the Common Core standards. Spaced repetition
decides what comes next: every round warms up on skills the child already
knows, climbs toward new material, and drops back to solid ground after a
miss.

It runs on **iPad and iPhone, Android, and in the browser**. It works
offline, has no ads, no accounts and no tracking, and keeps all progress on
the device.

**Play it in a browser:** <https://icodeforbananas.github.io/space-math/>

## How it works

- `src/lib/spaceMathSkills.ts`: every skill, easiest first. This order _is_
  the learning ladder. Adding a skill is one entry here plus its question
  type in the generator.
- `src/lib/spaceMathGenerator.ts`: builds a question (prompt, answer, choices,
  optional pictures) for a skill.
- `src/lib/spaceMathSchedule.ts`: spaced repetition across rounds and
  momentum within a round. The comment at the top explains the rules.
- `src/lib/progressStore.ts`: the on-device history behind the Progress
  screen.
- `src/SpaceMathApp.tsx`: the game screen.
- `src/pwa.ts`: web-only install support (service worker for offline play, the browser's install prompt).
- `android/` and `ios/`: native shells, generated by
  [Capacitor](https://capacitorjs.com), that load the built web app.

Progress lives in `localStorage` under two keys: `space-math-save` (stars and
the learning ladder) and `space-math-progress` (per-skill history).

## Develop

You need Node 22. For the native apps you also need JDK 21 and the Android
SDK (Android Studio installs both) for Android, and a Mac with Xcode for iOS.

```
npm install
npm run dev        # play at http://localhost:5173
npm test           # unit tests for the schedule, generator and progress store
npm run android    # build, sync and open in Android Studio
npm run ios        # build, sync and open in Xcode (macOS only)
```

No Mac or Android Studio? Push a branch or open a pull request: CI builds an
Android `.apk` and an unsigned iOS `.ipa` and attaches them to the run.

See [CONTRIBUTING.md](CONTRIBUTING.md) to get involved, and
[docs/RELEASING.md](docs/RELEASING.md) for how releases reach the stores.
